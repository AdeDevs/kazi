# KaziHub

KaziHub is a premier artisan and professional services marketplace designed to connect customers with vetted local experts (electricians, plumbers, carpenters, cleaners, tech support, etc.) across neighborhoods with instant availability tracking, transparent pricing, secure booking flows, and real-time chat.

## Key Features

- **Explore & Filter Professionals**: Easily filter local pros by category, neighborhood, rating, experience, and immediate availability.
- **Redesigned Professional Cards**: Clean, compact 14px-padding cards featuring matching avatar geometries (`rounded-2xl`), streamlined verification badges, and unified review/trust strips.
- **Dual Role Dashboards**: Toggle seamlessly between Customer and Professional views to manage bookings, active requests, earnings, and service listings.
- **Direct Messaging & Booking**: Interactive chat modal for direct client-artisan communication and step-by-step booking dispatch.
- **Dark & Light Themes**: Fully responsive UI supporting both light and dark modes with Tailwind CSS.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation & Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Tech Stack

- **React 18+** with TypeScript & Vite
- **Tailwind CSS** for styling
- **Lucide React** for icons
- **Motion** for animations
